# نمایش اتصال حسابداری «شایان» | نمونه‌کار BI

این پروژه **دادهٔ ساختگی** دارد و برای نمایش مفهومی مسیر خروجی حسابداری تا داشبورد مدیریتی فارسی است. هیچ اتصال، خروجی، مجوز یا انتساب تجاری واقعی به شایان وجود ندارد؛ نام آن صرفاً برای شرح معماری احتمالی استفاده شده است. نگاشت ستون‌ها فرضی است. این پروژه **فایل PBIX ندارد** و نتیجهٔ واقعی یک سازمان را نشان نمی‌دهد.

## اجرا
نیازمندی: Python 3.10 یا بالاتر، و دسترسی به بسته‌ها هنگام نصب. پس از نصب، خود برنامه و فونت از منابع محلی استفاده می‌کنند.

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python scripts/generate_all_data.py  # اختیاری؛ CSVهای آماده موجودند
python -m unittest discover -s tests -v
streamlit run app.py --server.port 8504
```

اپ شامل نمای کلی، دفتر کل، دریافتنی‌ها، پرداختنی‌ها و درباره است. تاریخ مبنای ثابت نمونه **۱۴۰۳/۱۲/۳۰ برابر 2025-03-20** است؛ روز سررسید جاری شمرده می‌شود. پول ریال صحیح است. برای بازتولید، اجرای مولد فایل‌های CSV داده را بازنویسی می‌کند. seed برابر 14030303 است؛ داده‌های بازسازی‌شده ممکن است با داده‌های مخزن یا سند هندآف دیگری یکسان نباشند؛ صرفاً جمع کنترلی دفتر برای این نسخه همان عدد خواسته‌شده است.

## فایل‌ها
- `data/` فایل‌های نمونه، فرهنگ داده و گزارش کیفیت.
- `model/MODEL.md`, `model/measures.dax` و `assets/model_diagram.svg`: طرح مدل و اندازه‌های پیشنهادی.
- `report/POWER_BI_BUILD_GUIDE.md`, `report/SHAYAN_EXPORT_MAPPING.md`, `report/theme.json`: راهنمای ساخت و نگاشت تحلیلی.
- `assets/preview.png`: تصویر واقعی صفحهٔ اول برنامه؛ فونت محلی با مجوز SIL OFL در `assets/fonts/`.
- `VALIDATION.md`, `LIMITATIONS.md`, `SOURCES.md` و مطالعهٔ موردی انگلیسی.

**نکته شمارش:** ۱٬۵۰۰ سند مستقل، هر کدام دو آرتیکل دارد، پس فایل دفتر **۳٬۰۰۰ ردیف** دارد. بیان «۱٬۵۰۰ ردیف و ۱٬۵۰۰ سند متوازن» برای سندهای حداقل دوطرفه ناسازگار بود؛ در این بازسازی شمار سند حفظ شده است.

برای کاربرد واقعی: با مجوز و محرمانگی نمونهٔ خروجی واقعی بگیرید، نگاشت را با مسئول سامانه و حسابدار تأیید کنید، ETL را بسازید و تطبیق دهید، سپس مدل و PBIX را در Power BI Desktop بسازید و اعتبارسنجی کنید. این نمایش توصیهٔ مالیاتی، حقوقی یا حسابداری نیست.
